# PreHack
> Pre-built Hackathon Wheels & Skills Library

## Introduction
### English
A centralized collection of ready-to-use code assets, universal frameworks, utility scripts and proven tech solutions for hackathons.
Save your time on redundant coding, focus more on logic innovation and product iteration, accelerate your team delivery in short-time competitions.

### 中文
整合黑客松全场景即用代码、通用框架、工具脚本与成熟技术方案。
节省冗余编码时间，专注创意逻辑与产品打磨，短赛制下极速完成项目交付。

## Content Classification
- 通用业务模板 General Project Templates
- 前后端轮子 Frontend & Backend Code Wheels
- 算法工具类 Algorithm & Utility Tools
- 第三方接口封装 Third-party API Wrappers
- 赛事实战技巧 Hackathon Practical Skills
- 部署上线快捷方案 Quick Deployment Solutions

## Usage
Clone this repo and directly reference modules you need, modify on demand to finish your project rapidly.
克隆仓库按需引用对应模块，按需二次修改，快速完成项目开发。

## Statement
All resources are sorted and summarized by personal actual combat experience, continuously updated and optimized.
所有资源均为个人实战整理汇总，持续更新迭代优化。
