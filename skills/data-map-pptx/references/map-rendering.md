# 地图渲染规则（geo_map.py）

`scripts/geo_map.py` 把省界 GeoJSON 变成绘图数据，与展示层完全解耦：返回 dict 既喂 python-pptx（自由多边形）也喂 HTML/SVG。核心规则如下。

## 投影

- **Albers 等积圆锥投影**，标准中国地图画法：双标准纬线 27°/45°、中央经线 105°、中心纬线 36°。
- 画布 y 轴向下，投影后数学 y 取负，否则整图南北颠倒。
- 主图按 1000px 基准排版；南海小图按 300px。

## 色阶与分档

- 颜色深浅 = 得分高低：**深=高分**。默认 `DEFAULT_RAMP = ['#1F4E79', '#4A80C0', '#7FA8D8', '#AECBE8', '#D9E6F2']`（5 档深到浅蓝）。
- 分档按**名次**：`DEFAULT_BINS = [(1,3),(4,5),(6,8),(9,12),(13,15)]`，即第1-3名用最深档、13名以后用最浅档。
- 名次用并列同名次（分数相同则名次相同），分档跳过空档。
- 非目标省统一灰色 `#EFEFEF`。
- 改色阶/分档：改 `DEFAULT_RAMP` / `DEFAULT_BINS`，或调 `build_map(..., ramp=, bins=)`。

## 边界与抽稀

- 省界 GeoJSON 来自阿里 DataV（`data/china_bound.json`），多边形用 Douglas–Peucker 抽稀（tol=0.012），既保形状又控制 PPT 体积。
- 极小碎片环（面积阈值）跳过，避免南海岛屿碎点干扰。

## 标签定位

- 全部省级单位都标（港澳除外）：目标省显示 `省名 + 分数` 两行、加粗；非目标省灰色小字单行。
- 落点算法：bbox 中心 → 顶点均值 → 3×3 网格扫描，用 **PIP（点在多边形内）** 保证标签落在省内；窄省自动降字号。

## 图例

- 按分档区间生成：`第1名（xx分）`、`第4-5名（xx-yy分）`…；同分区间合并显示。
- 目标省之间若某档无人（并列跳过），图例跳过该段。
- 图例最后固定补一条 `非调研省份（灰）`。

## 方向自检

- 生成后断言：黑龙江 y < 广东 y（北在上）、江苏 x > 新疆 x（东在右），颠倒立即报错，防止投影参数搞错画出倒公鸡。

## PPTX 侧换算

`build_map` 返回 `_proj`（主图原点和缩放）、`_iproj`（南海小图）、`_rings_main`（投影后环坐标）。`gen_pptx.add_map_slide` 按 `MW = min(可用宽, 可用高×宽高比)` 自适应，把环坐标乘 `scale = MW×914400 / W` 转 EMU 画自由多边形；标签/图例坐标同理按 `MW / W` 比例映射到英寸。
