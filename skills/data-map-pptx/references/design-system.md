# PPT 版式规范（gen_pptx.py）

## 画布

- **13.333" × 7.5"**（16:9，python-pptx 的 `Presentation()` 默认就是）。
- 所有坐标/尺寸用英寸（`Inches()`）。

## 字体

- 中文：**微软雅黑**；西文同字体族（不另设）。
- 设置中文字体必须同时写 `<a:ea>`（`set_ea` 辅助函数），否则中文回退默认字体，版式崩。

## 配色

| 用途 | 色值 |
|------|------|
| 标题条 / 表头 / 结论条背景 | `1F4E79`（深蓝） |
| 标题条文字 | `FFFFFF` |
| 地图主色阶（深→浅） | `1F4E79` `4A80C0` `7FA8D8` `AECBE8` `D9E6F2` |
| 地图非目标省 / 条形网格线 | `EFEFEF` / `E3E9F0` |
| 评级档位（1→5档） | `C6EFCE` `E2EFDA` `FFEB9C` `FCE4D6` `FFC7CE` |
| 地图深色省内标签文字 | `FFFFFF`；浅色省内 `17406B` |
| 非目标省标签 | `999999` |
| 依据页短板列底 / 省份列底 | `FFF8E7` / `EAF1F8` |
| 次要文字 | `666666` `888888` |

色值均不带 `#`，大写 6 位 hex（python-pptx `RGBColor.from_string` 要求）。

## 页型

### 地图页（每评分维度一张 + 综合一张）

```
标题条（0.5,0.28,12.33×0.62 深蓝）      ← 标题 = PPT标题 · 维度名
副标题（0.55,0.98 灰小字）
[中国地图 自由多边形]        [右栏: 结论速览（前三/末三/注释）]
[南海小图 0.9in @ 右栏底]   [右栏: 图例色块 + 非调研省说明]
```

- 地图区：`MX=0.55`，可用宽 8.05in / 高 5.85in，按宽高比自适应；右栏 `LX = max(8.75, MX+MW+0.35)`。
- 南海小图固定在 `(LX, 5.62)`，加白底灰边 + "南海诸岛"标注。

### 综合排序条形页

- 横条起点 `(2.3, 1.55)`，宽 9.0in，行高 0.355in；序号右对齐在 `0.5` 起 1.7in 宽。
- 每个维度一段颜色（前深后浅：`1F4E79` `5B9BD5` `9DC3E6`…，最多 6 段）。
- 垂直网格线每 5 分一条（0/5/10/15/20 位置），刻度按满分换算。

### 维度矩阵表页

- 表格起始 `(0.55, 1.45)`，表头行深蓝白字 10pt 加粗，行高 0.42in。
- 列序：`省份 | 名次 | 总分 | 评级×N（彩色档位格） | 维度总分×M`。
- 数据行 0.36in，评级格填档位色并加粗，省份列加粗。

### 依据与短板页

- 每 5 省一页；列序：`省份 | 各维度评分依据（自动拼接） | 关键短板`。
- 短板列浅黄底（`FFF8E7`）深棕字（`7F6000`）；行高按文本长度自适应（上限 1.1in）。

### 评级规则页

- 标题 + 文本块（11pt，行间距 3pt）。

## 备注

- 所有对象均为原生：地图=自由多边形、表格=`add_table`、文字=文本框。**禁止截图填图**，保证交付后可编辑。
- 生成用 tmp+`os.replace` 落盘，目标被 PowerPoint 占用时抛 `PermissionError` 且保留 tmp 供重试。
