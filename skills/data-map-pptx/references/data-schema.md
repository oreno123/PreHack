# 输入数据 Schema（data-map-pptx）

`gen_pptx.py` 读一个 JSON，含两个顶层节：`省份`（评分数据）+ `_config`（配置）。完整可跑示例见 `examples/example_data.json`。

## 顶层结构

```json
{
  "省份": { "<省短名>": { ...字段... } },
  "_config": { ...配置... }
}
```

省短名用不带"省/自治区"的短名（如 `山东`、`黑龙江`、`广西`），必须与 `data/china_bound.json` 里的省名一致（`geo_map.short_name` 会自动去后缀匹配）。

## `省份` 节的字段

每个省一个对象，可用的字段前缀：

| 前缀 | 含义 | 是否必填 | 示例 |
|------|------|---------|------|
| `score_<维度>` | 该维度的原始分（数值，可小数） | 至少一个 | `"score_用户侧": 7` |
| `评级_<维度>` | 该维度档位评价（词，不计分） | 可选 | `"评级_用户侧": "第一档"` |
| `依据_<维度>` | 该维度评分的依据文本 | 可选（有则出依据页） | `"依据_用户侧": "峰谷价差... + 补贴..."` |
| `短板` | 关键短板文本 | 可选 | `"短板": "现货试运行期间调峰暂停"` |
| 其他任意字段 | 不影响生成 | — | `"来源": "..."` |

维度名是自由的，但 **`score_` / `评级_` / `依据_` 三个前缀的维度名必须一一对应**（如都有 `用户侧`），`依据_` 就是依据页的取字段方式。

## `_config` 节的配置

```json
{
  "title": "PPT 标题（每页地图页显示为 `标题 · 维度名`）",
  "subtitle": "副标题（显示在每页标题条下方）",
  "note": "地图页结论速览的注释（可选）",

  "groups": {
    "<维度组名>": {
      "keys":   ["score_用户侧", "score_独立储能"],
      "cap":    20,
      "note":   "该组的注释，显示在地图页副标题"
    }
  },

  "综合": {
    "weights": { "<维度组名>": 0.4, "...": 0.4, "...": 0.2 },
    "note":    "综合权重的说明"
  },

  "等级_填充": { "第一档": "C6EFCE", "第二档": "E2EFDA", "第三档": "FFEB9C", "第四档": "FCE4D6", "第五档": "FFC7CE" },

  "rule": "评级规则说明文本（有则生成规则页，多行用换行分隔）",

  "bound": "省界 GeoJSON 路径（可选，默认 scripts/../data/china_bound.json）"
}
```

### groups：维度聚合

`groups` 把多个 `score_` 分项聚合为一个"地图维度"。每组成员合成一张地图页。

- **keys**：要聚合的 `score_` 字段（不含前缀的维度名，脚本自动补 `score_`）。例：友好度 = `["用户侧", "独立储能"]`。
- **cap**：该组满分（用于综合归一）。默认 10。若组内两分项各满分 10，cap 应设 20。
- 不配 `groups` 时：自动把所有 `score_` 字段各当一组。

### 综合：加权总分

- `weights` 的键必须与 `groups` 的组名一致。
- 综合分 = Σ `权重 × (组原始分 / cap)`，即各先归一到 10 分再加权。
- 不配 `weights` 时：综合分 = 各组原始分直接相加（此时 cap 无效）。

### 等级_填充：评级档位色

矩阵表里评级列的格色。缺省用默认五档（绿/浅绿/黄/橙/红）。自定义只改要覆盖的档位即可。

## 生成规则速查

| 你想让脚本生成什么 | 需要的数据 |
|--------------------|-----------|
| 每维度一张地图页 | `_config.groups`（或自动发现 `score_`） |
| 综合地图页 + 排序条 + 矩阵表 | 必须有（自动生成） |
| 依据与短板页 | 任意省含 `依据_<维度>` 或 `短板` 字段 |
| 评级规则页 | `_config.rule` 非空 |
