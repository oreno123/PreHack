# PPT 风格卡

## 基线（安全区）

- **全白底 + 衬线字标题 + 无衬线正文**，杂志风排版
- 图文混排走杂志网格：大图跨栏、文字块对齐网格线
- 版式靠留白和对齐撑，不靠装饰元素

## 已知雷区（实测翻过车）

| 雷 | 后果 |
|---|---|
| 描边卡片 | 一加就廉价，用底色块或纯留白替代 |
| 深色底 PPT 投影 | 现场投影仪发灰，深底全糊 |
| 截图拼版 | 不可编辑=返工地狱，用可编辑重建 |
| 嵌入字体跨机器 | 换机器丢字体，输出 PDF 兜底 |

## 工作规则

- **先出风格样张（2-3 页）过目，再批量生成全册**——风格没定就生成 30 页 = 全部重做
- 方案被否 ≥ 2 次时，停止改参数，改出 A/B mockup 对比让人选
- PPT 是视觉件、讲稿是口径件：分开维护，PPT 里不放长句
