# 配色卡

## 等明度体系（实战命中率最高的策略）

对大量被验证"好看"的案例反推：**等明度组合约占 80% + 低饱和（20-35%）占主导**。

操作法：
- 选一组色相不同、**明度几乎相同**的颜色做主色板（同明度不同相）
- 饱和度压在 20-35 区间，需要强调时局部破格（一处高饱和焦点色）
- 灰阶用同色相的深浅，不用纯灰（纯灰显脏）

## 色阶工具

- 用 **Radix Colors** 这类现成色阶体系（12 档明度分阶），按档位选色而不是挑单色值
- 换主题只换 scale 档位映射，不动逻辑

## 深浅底规则

- **黑底作品必配一套浅底版本**：投屏用深底、打印/文档用浅底，两套都要有
- 深色 UI 的玻璃材质 = 低 alpha + **窄 specular**（宽高光显塑料感）
- 浅色界面**别做旧**（别加做旧纹理/米黄底/复古颗粒）——参照高德的干净现代感，浅色就是要干净

## 快速诊断

| 症状 | 药 |
|---|---|
| 土 | 饱和度全线拉太高，压到 20-35 |
| 脏 | 灰阶混了不同色相的灰，统一色相 |
| 乱 | 颜色数超了——主色 2 + 强调 1 + 灰阶，其他全砍 |
| 平 | 全等明度没有焦点，加一处明度/饱和双破格 |
