# 排版卡

## 字号字重（NIO 风经验）

- **大字号 + 负字距，不加粗**：高级感来自尺寸和密度，不是 bold
- 标题区用大号字收紧 tracking；正文保持常规字重、常规行距
- 数字/英文混排时负字距尤其有效（数字天然松）

## 信息密度

- 长文档（讲义/报告）走**浅色主题 + 高信息密度**，密而不挤的分界=行距 1.6-1.8
- 展示页（落地页/海报）相反：信息做减法，一屏一个主张
- 表格是密度工具不是装饰：能用表格对齐的别用列表堆叠

## 通用

- 中文字体别拉负字距过头，负值给到字宽的 2-4% 封顶
- 一页最多两级字号层级（大/正文），第三级用颜色区分而不是再缩一号
