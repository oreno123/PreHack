# color-system-cheatsheet · 配色与排版经验卡

设计决策速查：什么配色能过、什么字重高级、PPT 什么样不翻车。全部来自项目实战验证（网页/海报/PPT 多场景），不是理论书。

## 卡片

| 卡 | 内容 |
|---|---|
| [cards/color.md](cards/color.md) | 等明度体系、色阶工具、深浅底规则 |
| [cards/typography.md](cards/typography.md) | 字号字重负字距、信息密度 |
| [cards/ppt-style.md](cards/ppt-style.md) | PPT 白底衬线杂志风、已知雷区 |

## 总律（三张卡共用）

1. **结构 > 配色**：版式和信息层级没定，禁调色
2. **参照先行**：动手前钉 3-5 张参照图，学结构不抄皮（复刻 ≠ 好看）
3. **先出 10 分钟样张**：方向拿不准，先出小样给自己/他人看再深入
