- [cards/01-problem-types.md](cards/01-problem-types.md) — 九大题型与出题趋势

## 契约

| 字段 | 值 |
|---|---|
| stages | [0, 1] |
| input | 无（查阅型） |
| output | 选题快评依据 + 可套用的建模链路 |
| use_when | 赛前备卡；72h 开赛 3 题快评；建模链路选型 |
| not_for | 零基础学建模（本卡是套路速查不是教材） |
| integration_time | 0（翻开即用） |
