# 阶段 5 · 交付物

**目的**：按画像卡清单产出全部交付物，格式逐字达标。

**输入**：demo + 画像卡的交付物清单。

**输出**：逐项交付物（视频 / PPT / 传单 / README / 答辩稿 / BP…），每项对照过格式。

## 任务清单

1. 把画像卡交付物清单抄成待办，逐项做、逐项勾
2. 每项做完，格式与公告要求**逐字**核对（格式硬要求原文对照）
3. 口径检查：金额、品牌、设备名、团队信息全部按画像卡雷区执行
4. 命名规范：文件名按提交要求来，没要求就用"队伍名_交付物_版本"
5. 视频类：先写逐秒脚本再剪辑，成片控制在时限内

## 退出条件

- 清单全勾，无缺项
- 每项格式与要求原文对过，不是"应该对"
- 口径检查通过

## 坑与检查点

- **输出格式不符 = 0 分**（美团教训，见 [cases/2026-meituan-zero-score.md](../cases/2026-meituan-zero-score.md)）
- PPT 走全白衬线、杂志风；大字号+负字距，不加粗
- 视频时长卡上限，别超 1 秒
- 讲稿与 PPT 分开维护，讲稿给口径，PPT 给视觉

## 工具

- skills: `slide-deck`、`pptx`、`frontend-slides`、`academic-pptx`、`video`、`jianying-editor`、`vlog-auto-edit`、`copywriting`、`huashu-md-html`
- 规划中：`image-pipeline`（截图/PDF/选片/抖动链）
