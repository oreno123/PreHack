# 阶段 3 · 设计

**目的**：把"做什么"定死成"评委看到什么"，让开发有据可依。

**输入**：选定题 + spike 结论。

**输出**：[90 秒演示脚本](../templates/demo-script.md) + 视觉方向一句话 + 页面/画面清单。

## 任务清单

1. 写逐镜头演示脚本（时间轴/画面/旁白/露出的技术点）
2. 定视觉方向一句话（参照色卡与风格参照物，结构先于配色）
3. 列页面/画面清单，逐项标注：用现成组件 / 要新做
4. 对照画像卡的评分权重，确认每个评分点都有镜头露出

## 退出条件

- 对一个陌生人讲一遍"打开后看到什么"，对方能复述出来
- 每个镜头都知道由什么实现（组件名或"新做"）
- 演示脚本覆盖画像卡里的全部评分维度

## 坑与检查点

- 结构 > 配色：信息架构定不下来时别调色
- 要做 X 之前先查手里有没有 X（组件、素材、历史页面）
- 复刻 ≠ 好看：参照物是用来学结构，不是抄皮
- 黑底产品图记得配浅底版本，投屏和打印两种场景

## 工具

- skills: `taste-skill`、`wireframe-spec`、`visual-hierarchy`、`critique-*` 系列、`color-system`
- 参照：PPT 参考库清单（只看结构与版式，文件不进仓）
