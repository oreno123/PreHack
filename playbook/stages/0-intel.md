# 阶段 0 · 情报

**目的**：把比赛规则变成结构化画像，格式雷区在动手前就暴露。

**输入**：比赛公告 URL / PDF / 群通知 / 往届信息。

**输出**：一份[比赛画像卡](../templates/profile-card.md)。

## 任务清单

1. 通读公告+附件+FAQ，一条不跳
2. 查往届获奖名单和作品，找评审偏好规律
3. 交付物逐项列出，每项抄下格式硬要求（格式、大小、时长、命名）
4. 找评分权重和评审构成（技术评委还是市场评委，决定讲什么话）
5. 标雷区：格式不符、口径禁词、必须包含/禁止包含的内容
6. 在画像卡上判型（UC1-UC5），写下对应的 flow 文件名

## 退出条件

- 画像卡填满，没有空格（不确定的格子写口语问句，不空着）
- 交付物清单每项都有格式说明
- 雷区 ≥ 3 条，或明确写"确认无雷区"

## 坑与检查点

- **美团 0 分 = 输出格式不符**，全部工作直接归零。格式硬要求必须逐字抄进画像卡，不许 paraphrase（见 [cases/2026-meituan-zero-score.md](../cases/2026-meituan-zero-score.md)）
- 口径雷区要具体到品牌与数字（例：不写设备金额、设备名写官方型号）
- 公告有更新渠道的，把"最后检查日"写进画像卡
