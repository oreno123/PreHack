# Flow · UC8 设计征集型

**判型特征**：交付 = 设计稿 / 实物照片 / 设计说明，评审看视觉完成度与主题契合，线上提交为主。

**核心律**：参照先行、小样先行——先找参照图再动手，先出 10 分钟小样再深入。

## 阶段权重

| 阶段 | 权重 | 裁剪规则 |
|---|---|---|
| 0 情报 | 正常 | **加重主题解读**：征集主题逐句拆；往届获奖风格找 3 例做参照 |
| 1 选题 | 换成方向发散 | 3 个视觉方向并行，各自一句话概念 |
| 2 spike | 换成小样 | 每方向 10 分钟样张 ×3，先看小样再决定深入哪个 |
| 3 设计 | **加重** | 参照图板先行；主视觉定稿 → 延展系统（版式/配色/材质） |
| 4 构建 | 制作 | 2D 出图 / 3D 渲染 / 实物制作（实物走 UC4 打印链） |
| 5 交付物 | 正常 | 设计说明一页 + 展板排版 + 源文件导出 |
| 6 提交 | 正常 | **分辨率/色彩模式(RGB/CMYK)/文件格式逐字核**，设计赛格式死得最冤 |

## 差异规则

- 参照图先行：动手前先钉 3-5 张参照，学结构不抄皮（复刻 ≠ 好看）
- 10 分钟样张先行：方向不确定时先出小样给自己/他人看，再投入
- 结构 > 配色：版式与信息层级定不下来时禁调色
- 配色走等明度体系（等明度≈80% + 低饱和 20-35），需要破格再破格
- 黑底作品配浅底版本一套，投稿与投屏两用

## 工具

- skills: `taste-skill`、`color-system`、`mono-color`、`critique-*` 系列、`illustration-style`
- 素材：设计素材库、公共资产（CC0）优先
