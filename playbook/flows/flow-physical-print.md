# Flow · UC4 实物打印

**判型特征**：交付含实物（3D 打印、定制件、装配件）。

**核心律**：打印失败缓冲前置——打印周期不可压缩，倒排日历从交货日往回推。

## 时间轴（倒排）

| 阶段 | 裁剪规则 |
|---|---|
| 0-2 | 同常规，但 spike 必须包含**一次真实小件试打**（验机器与耗材） |
| 3 设计 | 建模规格前置：尺寸公差、槽深、装配间隙写进设计文档 |
| 4 构建→打印链 | 建模 → 水密检查 → 修复（体素+MC 平滑）→ 切片 → 试打 → 真机验收 |
| 5 交付物 | 含实物照片拍摄；装配说明一页纸 |
| 6 提交 | 实物寄送/交付单独列节点，与线上材料分开跟 |

## 差异规则

- 失败缓冲 ≥ 2 轮 × 3 天：第一轮必失败是常态，按两轮失败倒排
- 水密检查前置到切片之前，别等切片器报错才发现
- 真机验收才算阶段 4 完成：装机/装配/上手试，照片留档
- 材料收缩率、槽深公差这类参数记进组件文档，下次直接复用

## 工具与案例

- 规划中组件：`3d-print-kit`（网格修复配方 + 纹样→STL 链）
- 案例：大衍筮筹 3D 打印（成功交付）、龙门 iPad 展框（trimesh 改件）、掐丝器（真机验收）（外部案例，待补卡）
