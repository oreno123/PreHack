# Flow · UC7 创新创业 BP 型

**判型特征**：商业计划书为核心交付，初审书面评审，晋级后决赛路演（接 [UC3](flow-pitch-defense.md)）。

**核心律**：叙事线一页讲清（痛点→方案→壁垒→市场→财务），市场验证重于产品开发。

## 阶段权重

| 阶段 | 权重 | 裁剪规则 |
|---|---|---|
| 0 情报 | 正常 | **加重评审构成**：投资人评委看回报与壁垒，学者评委看创新性，配比决定叙事重心 |
| 1 选题 | 正常 | 选题=选赛道：痛点真实性优先于技术新颖性 |
| 2 spike | **加重** | 市场验证：规模测算（自下而上）、竞品格局、数据可得性，全走数据纪律红线 |
| 3 设计 | 换成叙事线 | 一页故事线定稿：痛点→方案→壁垒→市场→财务→团队 |
| 4 构建 | 最小化 | demo 能支撑故事即可，别过度开发 |
| 5 交付物 | **加重** | BP 文档 + 财务模型附录 + BMC 九格；晋级则追加路演 PPT 与讲稿 |
| 6 提交 | 正常 | 页数/格式/命名逐字核 |

## 差异规则

- 财务预测给区间不给假精确；关键假设在附录可查
- "凭什么是你"必须有专页：壁垒 = 数据 / 专利 / 渠道 / 先发，实在没有就写诚实版
- 市场规模自下而上测算（单价×客户数×渗透率），禁只抄行业报告总数
- 评委口径雷区照画像卡执行；红档（法律灰色）赛道直接放弃
- 晋级后 = 切 UC3 流程，BP 内容重构为 7 分钟讲稿
