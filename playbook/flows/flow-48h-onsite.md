# Flow · UC1 现场 48h

**判型特征**：现场开发、48 小时内交作品、通常带现场路演评奖。

**核心律**：组件复用率 = 生命线。现场禁从零写，所有大件都应该从 PreHack 取。

## 时间轴（48h 预算）

| 阶段 | 预算 | 裁剪规则 |
|---|---|---|
| 0 情报 | 2h | 通常赛前已完成；现场只补 FAQ 更新 |
| 1 选题 | 1h | 候选 ≤ 2，靠现成资产筛 |
| 2 spike | 3h | 只验 1 个最致命假设，1 端点即可 |
| 3 设计 | 2h | 演示脚本先于代码，镜头数压到最少 |
| 4 构建 | ~24h | 主战场，骨架上线后并行填镜头 |
| 5 交付物 | 与 4 并行 | 边做边录屏/截图，别等做完 |
| 6 提交 | 留 2h 缓冲 | 现场网络不可信，提前演练提交通道 |

## 差异规则

- 睡眠预算写进计划：第一天通宵换第二天降智不划算，留 5h 睡眠线
- 演示脚本里每个镜头绑定现成组件名，绑不到的镜头考虑砍掉
- 路演彩排至少 1 遍：90 秒讲不完的功能不做
