# Flow · UC10 AI 内容创作型

**判型特征**：交付 = AI 生成的视频 / 图像 / 多模态作品，评审看创意与完成度，线上提交为主。与 UC1 区别：非现场、周期数天到数周、生成迭代是主要工作量。

**核心律**：批量抽优——生成质量方差大，一轮多抽再筛，别盯着单张调 prompt。

## 阶段权重

| 阶段 | 权重 | 裁剪规则 |
|---|---|---|
| 0 情报 | 正常 | **加重 AI 使用规则**：允许的工具范围、AI 使用声明要求、署名规则逐字抄 |
| 1 选题 | 换成创意 | 一句话创意 + 故事板概念（起承转合 4 格） |
| 2 spike | 生成链验证 | 用 remote-batch-studio 跑 3-5 组对比：哪个模型/参数出什么质量，选定主生成链 |
| 3 设计 | 换成分镜脚本 | 逐镜头 prompt 草案 + 时长表；镜头数=预算约束 |
| 4 构建 | **主战场** | 批量生成 → keep/reject 筛选 → 失败镜头改 prompt 重抽；提示词迭代全程留档 |
| 5 交付物 | 后期 | 剪辑 / 配音 / 字幕 / 调色；导出前对公告编码规格 |
| 6 提交 | 正常 | 编码/分辨率/时长/AI 使用声明逐字核 |

## 差异规则

- 一轮多抽：每镜头 ≥ 4 抽再筛，抽不出的镜头改写 prompt 而不是加抽
- 重生成包导出留档：下轮迭代直接从上轮保留项出发
- 免费视觉评估链（VLM 打分）先跑，人眼只看高分池
- AI 使用范围声明按公告原文，多写少写都违规
- 生成素材留原始出处与参数，答辩被问"怎么生成的"要有答案

## 工具

- components: `remote-batch-studio`（批量生成 + VLM 打分 + 筛选）
- skills: `jianying-editor`、`vlog-auto-edit`、`video`、生成系 PPT/图像 skills
