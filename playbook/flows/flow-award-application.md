# Flow · UC13 成果报奖型

**判型特征**：拿现成作品/成果包装申报，几乎零新开发，材料工程是全部。最便宜的一型——但要便宜得讲究。

**核心律**：申报条款逐条对到自己成果的证据上；材料口径全篇一致，经得起并排细看。

## 阶段权重

| 阶段 | 权重 | 裁剪规则 |
|---|---|---|
| 0 情报 | **一半重心** | 申报条款逐条拆；每条写明对应自己哪个成果、哪个证据（照片/数据/链接/证书） |
| 1-4 | 跳过 | 成果已在；缺口大的材料宁可放弃该奖项，别为报奖临时造工程 |
| 5 交付物 | **另一半重心** | 申报书按模板逐格填；成果清单+证据链编号管理；图片视频重打包 |
| 6 提交 | 正常+缓冲 | 盖章/证明/签名类材料周期长，**提前发起**；清单逐项核 |

## 差异规则

- **条款-证据对照表**是本型的画像卡变体：每条评审条款一行，右侧贴证据编号，空白行=要么补要么删该主张
- 口径统一：同一成果在申报书、PPT、传单里的数字/说法/时间线完全一致（评委最爱交叉核对）
- 成果与条款错位时诚实降级申报档位，硬凑高档=白干
- 同一成果报多个奖项：材料各自独立改写，别一份通用稿撒网（每奖的条款措辞不同）
- 证据材料全量归档一份（私有仓），申报被质疑时可调
