# Flow · UC9 晋级制作品赛

**判型特征**：校赛 → 省赛 → 国赛多轮晋级，同一作品数月迭代，每轮材料递进。

**核心律**：每轮 = 一次完整 mini 流程 + 一轮定向增量改进；版本树管理，禁推倒重来。

## 结构

```
报名 → 校赛轮(UC2 压缩版) → [晋级] → 增量窗口 → 省赛轮 → [晋级] → 增量窗口 → 国赛轮
每轮赛后 48h 内：复盘卡 + 评分反馈回写画像卡
```

## 每轮内的阶段裁剪

| 轮次 | 裁剪规则 |
|---|---|
| 首轮（校赛） | UC2 压缩版：完整但轻量，先活下来；材料按国赛标准建档（后面轮次只增量） |
| 增量窗口 | **评委视角 diff**：找上一轮最弱的两项专攻；其余只做维护性微调 |
| 中后轮（省/国） | 按 UC3 加重：路演与答辩权重逐轮上升；作品本体改动冻结、只补短板 |

## 差异规则

- 版本树：`v1-校赛 / v2-省赛 / v3-国赛` 各自完整归档，任何一轮可回滚
- 评分反馈是唯一改进依据：拿到反馈先回写画像卡，再排改进优先级
- 别推倒重来：评委与作品连续性是资产，大改 = 重新冷启动
- 轮间隔长（月级）容易松：倒排里程碑，每两周一个可交付节点
- 国赛材料只加不改底稿结构（评委见过前版，突变反而扣分）

- 中国大学生计算机设计大赛·数媒（2023 校级经历，复盘待补）
