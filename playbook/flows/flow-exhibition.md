# Flow · UC15 策展展示型

**判型特征**：交付 = 空间叙事（展项 + 动线 + 观展体验），开幕式/验收即"提交"。周期数周，含布展时间窗。

**核心律**：动线即叙事——观众怎么走就是故事怎么讲；展项台账是唯一可信的管理工具。

## 阶段权重

| 阶段 | 权重 | 裁剪规则 |
|---|---|---|
| 0 情报 | 换成场地情报 | 尺寸/层高/电源点位/网络/采光/承重；布撤展时间窗；安防与设备借还规则 |
| 1 选题 | = 主题叙事 | 一句话主题 → 分幕结构（起承转合映射到空间段落） |
| 2 spike | 展项可行性 | 每类关键展项（屏/投影/实物/交互件）逐个验：内容源、驱动设备、故障模式 |
| 3 设计 | **加重** | 动线图 + **展项台账**（编号/名称/尺寸/媒介/内容/负责人/状态）；线上线下一案两做（双模式） |
| 4 构建 | 展项制作+进场 | 安装顺序倒排（先重后轻、先高后低）；数字展项全部真机联调 |
| 5 交付物 | 展签导览物料 | 展签=站着读的短句；导览词=走一遍的节奏；宣传物料另走 UC8 |
| 6 提交 | = 开幕验收 | 全动线亲走一遍 + 应急预案（断电/断网/黑屏的降级方案逐项过） |

## 差异规则

- 数字展项必配模拟器/离线备份：现场网络不可信，主案挂了 3 秒内切备份
- 展项台账状态实时更新（idea→制作→到场→安装→验收），台账滞后 = 现场必乱
- 展签文案短句制：一行主题一行说明，超过三行没人读
- 观展节奏设计：入口 30 秒抓住（同 UC1 演示脚本律），出口留记忆点
- 布展时间窗永远不够：主体展项提前完成，现场只做安装微调

## 工具

- components: `galaxy-scene`（数字展项/氛围屏）、`image-pipeline`（规划中，展项图生产）
- skills: 设计系 skills、`copywriting`（展签导览）
