- **时间**：2026-09-30 交包（UC12 命题平台 + UC7 作品赛复合型）
- **结果**：复赛未获奖（任何奖次均未获得），线关闭

## 核心教训（反面）

1. **评委怎么验货要看日志，不能靠想象**。赛后 nginx/数据库取证：评审核验走的是 HeadlessChrome 巡网页版（演示账号登录、全量字体、3D 页、试拍照识别），全月 0 个鸿蒙 UA——**平台指定交付 HAP，评委未必真跑 HAP**。网页版等价物必须和 App 同等完美，两边是两套独立故障源，各自都要走查
2. **付费 API 在评审窗口欠费 = 核心功能当场死亡**。拍照识别（第一入口）走的 VLM 在评审期余额耗尽全 402，评委最后动作 = 连试两次 402 后离场。降级横幅挂在结果页顶——评委看到的第一个功能就是"AI 识别不可用"
3. **签名链路是平台赛的知识壁垒**：debug profile 只绑一个写死的模拟器 UDID（任何模拟器都能装、所有真机都不能）；release 包不能 hdc 侧载（判 untrusted source），正路是 AGC 内部测试。验签名按字节指纹（development-certificate / device-ids 标记），不看文件名不看体积
4. **字数口径按最严的算**：含空白 vs 不含空白差 60+ 字，按"含空白"压线才安全；附页（演示账号说明）放在文末会被"从标题数到文末"的评委算进正文字数
5. **交包日纪律 = 不新加东西**。临门塞未验证的新功能/新素材是最高频的翻车姿势
