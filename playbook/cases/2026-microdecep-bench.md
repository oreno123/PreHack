## 核心教训（正面：投稿前的方法论）

1. **novelty 审计先行，动实验前做完**：初始五条"创新点"逐条对文献审计，四条被撞（概念/范式/语言范式三条直接撞车），只留一条立足点——审计结果用色卡标注（红=删改/黄=降级/绿=可写）落成文档，别停留在口头
2. **"空白"声明必须搜索证伪**："中文××研究空白"的直觉被检索证伪（已有数篇同题工作）；novelty 表述从"首个"降级为"开放问题"——没搜过的空白不是空白
3. **撞车基准复现六课**（200 条全量复现一个 agent 欺骗基准后）：mini 跑量 n=3 的结论全被推翻（n≥20 起步）；judge 与 agent 同源有 40pp 级偏差；指标名用论文官方名不自创；开跑前先算 token 账；断点续传必做；成本刹车——先查余额再开并行，推理模型比非推理贵一个量级
4. **复现分歧归因要分离变量**：结果与原论文差 40pp，候选原因（模型版本漂移 vs judge 偏差）列开分别设计实验，别混写成"复现失败"
5. **暂停也是决策**：施工图（数据集规格/论文骨架/投稿工程）齐了但主实验未开——保留砍范围预案（保核心 claim）优于硬冲 deadline
