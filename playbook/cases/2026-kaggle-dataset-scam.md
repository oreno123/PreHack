# 案例 · 2026 Kaggle 中文纹样数据集 · 踩坑

- **时间**：2026 上半年（UC11 数据竞赛 · 数据集踩坑）
- **结果**：790MB 白下。名为 "Chinese ICH Visual Design Dataset"（119K 文件），实际内容 = 105K 中国书法 OCR 训练集 + 11.7K 印尼蜡染纹样 + 2.5K Reddit 油画，与"中华传统纹样"几乎无关

## 核心教训（反面）

1. **Kaggle 标题党数据集不少，下载前先验货**：先用 kagglehub 拉 metadata/CSV 看目录结构和文件命名，确认内容再下全量——大文件的"预览成本"远低于"白下成本"
2. **数据集名 ≠ 数据内容**：命名带 "Chinese" 不代表内容是中国的（本案混入印尼蜡染）；抽查要看**实际图像**而非目录名
3. **垂直需求走官方渠道**：中华传统纹样这类需求，优先官方/学术库（如故宫民族文化记忆符号库，需申请审批）而不是公开数据集市场
