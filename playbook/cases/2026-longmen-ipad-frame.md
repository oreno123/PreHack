# 案例 · 2026 龙门 iPad 展框 · 3D 打印件交付

- **时间**：2026-09-22 定稿交打印（UC4 实物打印）
- **结果**：4 件 STL 四审定稿交付打印包（两件式滑槽结构，含打印说明）

## 核心教训（正面：数字件交付的验证纪律）

1. **超幅拆件方案比硬塞聪明**：打印幅面 256³ 装不下 274.6mm 件 → 上下两段切 + 方榫开口槽定位；首版 bisect 切件 + 圆销 boolean 被**推翻**（bisect 不封口留开放网格、boolean 静默失败）——二版全轴对齐 box 直接拼装，面数更少且无碎面
2. **STL 交付必须文件级验证，不信建模软件内存**：字节级边统计（每条边恰好被 2 个面共享）+ trimesh 加载后 split / is_watertight / euler_number / 体积对账；多块拼装件用 manifold3d 布尔融合成单壳再导出
3. **公差是魔鬼，0.05mm 过盈就顶死**：槽壁 2.75 vs 销顶 2.70 装不进去；滑道按 0.3mm/边留隙——公差表写进打印说明
4. **官方尺寸要抠到屏幕区**：开口按机身几何中心切，但屏幕相对机身是偏置的（上下边框不对称）——开口偏高 8mm 会压屏露边；修完**插入方向从此定死**（厚边框端朝下），打印说明里写明"已定向，别旋转"
5. **"你确定"连环追问抓出两个真 bug**（销槽零间隙、切面不封口）——嘴上保证不算数，证据链才算数
6. **终检脚本要防呆**：终检自己抄错变换表会造成"两边全空的假 PASS"——脚本加非空断言（实体点数下限）防呆
