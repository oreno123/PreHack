## 十二个获奖样本的可复用套路（速查）

| 套路 | 典型赛题 | 链路 |
|---|---|---|
| 评价三件套 | 信贷决策、区域风险评估 | AHP + 熵权法组合赋权 → TOPSIS 排序 |
| 评价 + 系统动力学 + 蒙特卡洛 | 美赛 E 题 O 套路 | MGWR/熵权+TOPSIS 评估 → 系统动力学模拟反馈 → 蒙特卡洛敏感性 |
| 供应链题万能链 | 原材料订购运输 | 评价(AHP/TOPSIS 选商) → 整数规划(定量) → 网络优化(定路线) |
| 规划 + 鲁棒优化 | 种植策略、生产决策 | MILP + 蒙特卡洛处理价格/天气不确定性 |
| 机理 + 启发式优化 | 定日镜场、板凳龙 | 物理/几何机理建模 → 数值积分/ODE → 三分查找/GA 优化 |
| 预测双保险 | 蔬菜定价、奖牌预测 | ARIMA + Prophet/XGBoost 双模型 + 残差分析 + 预测区间 |
| 统计 → 聚类 → 分类 | 古代玻璃文物 | PCA 降维 → K-Means 聚类 → SVM/RF 分类 → 卡方/t 检验 |
| 图论 + DP + 随机过程 | 穿越沙漠 | 确定性 DP → 随机 MDP + 蒙特卡洛 → 多人博弈纳什均衡 |
| 网络科学跨界 | 音乐影响力（O 奖） | PageRank + 中心性 + SNA → PCA + K-Means 特征分析 |

**混合建模是主流**：近年 O 奖论文约 83% 用混合模型，典型三层 = 基础模型(30%) → 改进模型(50%) → 扩展模型(20%)。

## 国赛 vs 美赛（决定打法）

- 国赛 3 天 4 题中文，评审看**结果准确性**；美赛 4 天 6 选 1 英文，评审看**创新与写作**，Summary Sheet 独立评分，严格 25 页
- 国赛数据以题目附件为主；美赛鼓励自行搜外部数据
- 美赛允许 AI 但需声明；国赛查重严格
