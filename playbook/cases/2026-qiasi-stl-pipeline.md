# 案例 · 2026 掐丝器 · 纹样卡→STL 全自动管线

- **时间**：2026（UC4 实物打印）
- **结果**：成功交付。47 张传统纹样卡 + 21 张 AI 卡转凸丝 STL **零失败、全水密**，真机验收收官

## 核心教训（正面）

1. **敢批量是因为全自动**：纹样卡→凸丝 STL 一键管线（收边环 + 圆润化 + 滤碎丝三道工序），68 张卡零失败靠管线不靠手工修——批量实物交付前先把链路做成全自动，否则第 N 张必崩
2. **水密是 3D 打印的硬指标，每版全检**：不是抽检——非水密网格到切片机才炸，前置到管线里全量检
3. **真机验收是唯一收官标准**：HDR 金属渲染 + 丝脚接触影做得再好看，判词只有真机打出来的"还能用"算数；渲染图是卖点不是验收物
4. **渲染验收的 VLM 坑（三度坐实）**：VLM 对 SwiftShader（CPU 软渲染）截图**系统性低估**画质——离屏验收要么用真 GPU 渲染、要么人眼看，别让 VLM 给软渲染产物打分下结论
